# AegisAI — Platform Security Threat Model

## 1. Overview
This document formalizes the complete Security Threat Model for the AegisAI Platform (Phases 8.1–8.9). It details each vector across the unified platform stack covering Agent, RAG, Knowledge Graph, MCP, Workflow, Intelligence, Observability, and Execution subsystems.

---

## 2. Platform Threat Evaluation Matrix

| ID | Threat | Attack Surface | Existing Defense | Test Coverage | Remaining Risk | Severity |
|---|---|---|---|---|---|---|
| **T01** | **Authentication Bypass** | REST API endpoints, WebSocket connections | `get_current_user` FastAPI dependency validating JWT signature, expiration, and user active status. | `test_auth.py`, `test_platform_api_security.py` | Minimal (standard JWT rotation policies). | **CRITICAL** |
| **T02** | **Authorization Bypass** | Administrative and privileged capability execution endpoints | Server-side role & permission verification in `PlatformExecutionService` and endpoint guards. Frontend hiding is never relied on. | `test_platform_security_hardening.py` | None. Unauthorized roles receive HTTP 403. | **CRITICAL** |
| **T03** | **Insecure Direct Object Reference (IDOR)** | Execution IDs, Workflow IDs, Capability IDs | Explicit tenant query scoping (`workspace_id == current_user.workspace_id`) on all fetch/update/delete operations. | `test_workflow_tenant_isolation.py`, `test_platform_api_security.py` | None. IDs belonging to other workspaces return 404/403. | **HIGH** |
| **T04** | **Cross-Tenant Data Access** | Vector search, Knowledge Graph traversal, telemetry streams | Mandatory `workspace_id` filtering in vector retriever, graph persistence, telemetry buffers, and SQL queries. | `test_vector_retriever_tenant_isolation_and_threshold.py`, `test_platform_security_hardening.py` | None. SQLite/PostgreSQL foreign keys and application assertions enforce workspace boundaries. | **CRITICAL** |
| **T05** | **Workspace Spoofing** | Request headers, body payloads (`{"workspace_id": "other"}`) | `PlatformContext` and `SecurityContext` construct workspace identity strictly from authenticated JWT token, completely ignoring body parameters. | `test_platform_security_hardening.py` | None. Injected workspace IDs are discarded. | **CRITICAL** |
| **T06** | **Context Spoofing** | User-controlled metadata, forged execution context | `SecurityContext` constructor validates caller claims; security flags and trust levels are immutable post-instantiation. | `test_platform_security_hardening.py` | None. Client cannot inject elevation flags. | **HIGH** |
| **T07** | **Capability Permission Bypass** | Direct capability dispatch (`capability.execute`) | `CapabilityRegistry` evaluates `required_permissions` against caller's permission set prior to invocation. | `test_platform_capability_core.py`, `test_platform_security_hardening.py` | None. Inaccessible capabilities raise `PermissionError` (HTTP 403). | **HIGH** |
| **T08** | **MCP Permission Bypass** | Restricted tools, filesystem/network capabilities | Single-use HMAC-bound confirmation tokens required for dangerous operations; capability state verification. | `test_mcp_security_hardening.py`, `test_platform_security_hardening.py` | None. Restricted tools cannot execute without valid signed confirmation. | **HIGH** |
| **T09** | **Workflow Permission Bypass** | Workflow execution and human approval triggers | Role-based node evaluation and self-approval separation policies (requester cannot approve own execution). | `test_workflow_approval_rbac.py` | None. Policy enforcement is strictly server-side. | **HIGH** |
| **T10** | **Analytics Permission Bypass** | Observability and telemetry dashboards | `_validate_analytics_access` verifying `platform:analytics:view` permission or authorized roles. | `test_platform_observability_api.py` | None. Unauthorized queries rejected with 403. | **MEDIUM** |
| **T11** | **Secret Leakage** | Platform execution results, error outputs, logs | Recursive sanitization via `CredentialStore.redact_sensitive_dict` and `redact_sensitive_str`. | `test_failure_analytics_and_secret_redaction`, `test_platform_security_hardening.py` | Minimal (ongoing pattern updates for novel vendor key formats). | **HIGH** |
| **T12** | **Token Leakage** | Bearer tokens, JWT headers in stack traces | Specific regex patterns for `Bearer <token>`, `eyJ...`, `sk-...` masking in all telemetry and event feeds. | `test_telemetry_store_event_recording_and_sanitization` | None. Standard regex coverage. | **HIGH** |
| **T13** | **Prompt Injection** | LLM inputs, tool outputs, external web documents | Input sanitization, delimiter encapsulation, and output criticism filtering in `CriticAgent`. | `test_prompt_injection_defense.py`, `test_platform_security_hardening.py` | Residual LLM non-determinism (mitigated by bounded capability permissions). | **HIGH** |
| **T14** | **Expression Injection** | Workflow conditional branching and node formulas | AST-based safe `ConditionEvaluator` with zero `eval()` or `exec()` usage. | `test_workflow_security_hardening.py` | None. Only whitelisted comparison operations permitted. | **CRITICAL** |
| **T15** | **Server-Side Request Forgery (SSRF)** | MCP HTTP transport, Web fetch tools | Domain whitelisting, private IP subnet rejection (`127.0.0.1`, `10.0.0.0/8`, `169.254.169.254`), and protocol restriction. | `test_mcp_security_hardening.py` | None. Private and metadata addresses blocked. | **CRITICAL** |
| **T16** | **Path Traversal** | Document chunking, MCP file tools | Safe path normalization, `os.path.commonpath` verification against sandbox workspace roots. | `test_mcp_security_hardening.py` | None. Absolute and `../` escapes rejected. | **HIGH** |
| **T17** | **Command Injection** | Execution dispacher, OS shell wrappers | Zero `os.system()` or `shell=True` subprocess executions across the codebase. | `test_platform_security_hardening.py` | None. Subprocess invocations pass arguments as explicit lists. | **CRITICAL** |
| **T18** | **Unsafe Deserialization** | Cached objects, IPC message payloads | JSON-only serialization with Pydantic type validation; zero `pickle` usage. | `test_platform_api_security.py` | None. Standard JSON parsing. | **HIGH** |
| **T19** | **Race Conditions** | Concurrent execution cancellations, simultaneous approvals | Thread-safe locks (`threading.Lock`), database optimistic concurrency (`version` column), and atomic state checks. | `test_platform_resilience.py`, `test_workflow_concurrency_hardening.py` | None. In-flight transitions guarded. | **HIGH** |
| **T20** | **Replay Attacks** | MCP confirmation tokens, idempotent capability runs | Single-use confirmation token invalidation and cryptographic argument hash binding. | `test_mcp_security_hardening.py` | None. Reused tokens immediately return 400. | **MEDIUM** |
| **T21** | **Idempotency Bypass** | Duplicate execution requests | Idempotency key tracking in `PlatformExecutionService._idempotency_records` returning cached results. | `test_platform_resilience.py` | None. Duplicate runs are short-circuited. | **MEDIUM** |
| **T22** | **Resource Exhaustion** | Large payload submissions, infinite execution loops | Request payload size limits, bounded execution timeouts (`DEFAULT_TIMEOUT_MS = 60000`), concurrency caps. | `test_platform_resilience.py` | None. Over-limit executions aborted. | **HIGH** |
| **T23** | **Unbounded Execution** | Long-running asynchronous capability tasks | Enforced hard deadline timers with background task cancellation hooks. | `test_platform_resilience.py` | None. Tasks terminated on timeout expiration. | **HIGH** |
| **T24** | **Recursive Workflow Abuse** | Cyclic DAG definitions, sub-workflow recursion | Topological sorting cycle detector (`has_cycle`), `MAX_SUBWORKFLOW_DEPTH = 5` recursion guard. | `test_sub_workflow_recursion_and_self_invocation_detection.py` | None. Cycles and deep recursion rejected at validation. | **HIGH** |
| **T25** | **Recursive Intelligence Planning** | Multi-hop adaptive planner looping indefinitely | Hard bounds: `MAX_INTELLIGENCE_STEPS = 12`, `MAX_PLAN_DEPTH = 6`, `MAX_ADAPTIVE_ATTEMPTS = 3`. | `test_platform_intelligence_core.py`, `test_platform_security_hardening.py` | None. Exceeding attempts triggers fallback completion. | **HIGH** |
| **T26** | **Provenance Forgery** | Fake evidence injection in intelligent query responses | `ProvenanceTracker` verifies source ID ownership and workspace association before stamping provenance items. | `test_platform_security_hardening.py` | None. Fabricated source IDs are discarded. | **HIGH** |
| **T27** | **Trust Escalation** | Converting `UNTRUSTED_MCP` evidence to `VERIFIED_RAG` | Immutable `TrustLevel` enumeration; transformations require cryptographic/retrieval verification. | `test_platform_security_hardening.py` | None. Untrusted sources maintain untrusted status throughout lifecycle. | **HIGH** |
| **T28** | **Observability Telemetry Leakage** | Exposing raw Agent states or cross-workspace timelines | `PlatformObservabilityService` strictly scopes event buffers and aggregates only sanitized metadata. | `test_platform_observability_core.py`, `test_platform_security_hardening.py` | None. Agent private memory is never included in telemetry. | **MEDIUM** |
| **T29** | **Cache Isolation Failure** | Shared Redis keys between tenants | Key namespacing: `aegis:platform:{workspace_id}:{subsystem}:{key}`. | `test_platform_security_hardening.py` | None. Global un-namespaced keys forbidden. | **HIGH** |
| **T30** | **API Abuse & Fuzzing** | Deeply nested JSON, huge numbers, Unicode edge cases | Strict Pydantic model validation, parameter boundary checks, and standardized error responses. | `test_platform_api_security.py` | None. Malformed payloads safely rejected with 422/400. | **MEDIUM** |

## 3. Defense-in-Depth Summary
1. **Perimeter Layer**: JWT authentication and HTTPS termination.
2. **Context Layer**: Authenticated `PlatformContext` and `SecurityContext` immutable bindings.
3. **Execution Layer**: `CapabilityRegistry` RBAC guards and bounded timeout dispatchers.
4. **Data Layer**: Strict SQL/Vector/Graph tenant filtering by `workspace_id`.
5. **Observability Layer**: Automated credential redaction and workspace-scoped circular buffers.
