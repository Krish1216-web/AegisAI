# AegisAI - Implementation Roadmap

## Phase 1: Core Scaffolding (Completed)
- Monorepo folder setup.
- Frontend login page & interactive 3D landing page.
- Backend FastAPI core server setup.

## Phase 2: Base Services (Weeks 1-2)
- Relational database schema deployment (PostgreSQL).
- Redis session cache & refresh token rotation handlers.
- Auth endpoints & custom RBAC role validators.

## Phase 3: Cognitive Agent Layer (Weeks 3-4)
- LangGraph state definitions & Orchestrator graph paths.
- Planner task gantry compiler.
- Qdrant semantic memory retrieval integrations.

## Phase 4: MCP Tool Registry (Weeks 5-6)
- JSON-RPC WebSockets connector handlers.
- GitHub, File, and Slack tool servers activation.
- Permission approval popup blocks.

## Phase 5: Testing & Release (Weeks 7-8)
- Unit and Integration testing pipelines.
- EKS container deployment configurations.
