# AegisAI — Problem $\to$ Solution Engineering Matrix

This document contrasts the core limitations of traditional AI/LLM applications with the architectural solutions implemented in **AegisAI**.

---

| Enterprise AI Problem | Traditional LLM / Chatbot Flaw | AegisAI Architectural Solution | Implementation Evidence |
| :--- | :--- | :--- | :--- |
| **Context Amnesia & Lost State** | Conversational history is lost after session termination or truncated due to context window limits. | **Dual-Tier Memory Vault**: Ephemeral Redis working buffers + 1536-dim vector long-term memory with exponential time-decay scoring. | `app/core/agent/memory.py`, 82 unit tests in `test_memory_*.py` |
| **Unverified Hallucinations** | Generative models generate plausible-sounding but completely fabricated facts. | **Automated Critic Agent & Citation Provenance**: The Critic Agent verifies candidate answers against ground-truth RAG chunks and Knowledge Graph triples (threshold $\ge 0.85$). | `app/core/agents/critic.py`, `test_agent_critic.py` |
| **Fragmented Enterprise Knowledge** | Knowledge is scattered across PDFs, Word docs, relational databases, and implicit entity relationships. | **Hybrid RAG + Relational Knowledge Graph**: Multi-format document parser + sliding-window chunker + BFS shortest-path graph reasoning. | `app/services/document_processing.py`, `app/services/knowledge_graph/` |
| **Ad-Hoc & Dangerous Tool Scripts** | LLMs invoke custom Python scripts or direct APIs without standardization, sandboxing, or type validation. | **Model Context Protocol (MCP) Hub**: Implements standard MCP across 4 transports (SSE, HTTP, STDIO, WS) with JSON-Schema validation. | `app/services/mcp/`, 112 unit tests in `test_mcp_*.py` |
| **Server-Side Request Forgery (SSRF)** | Malicious prompts trick tool-calling agents into querying internal cloud metadata (`169.254.169.254`) or private networks. | **SSRF Defense Guard**: Outbound DNS resolution and IP filter strictly blocking loopback and private RFC 1918 subnets. | `app/services/mcp/mcp_security.py`, `test_secrets_ssrf_ai_security.py` |
| **Unsafe Autonomous Mutations** | Autonomous agents execute destructive database deletions or financial transactions without human oversight. | **Human-in-the-Loop (HITL) Approval Gates**: High-risk tool calls pause execution and require cryptographic approval from authorized maintainers. | `app/services/workflow.py`, `test_workflow_approval_gate` |
| **Rigid & Unmaintainable Agent Logic** | Complex multi-agent flows are hardcoded in monolithic Python scripts without visual inspection. | **Visual AI Workflow Studio**: Drag-and-drop ReactFlow canvas with 8 node primitives, Kahn's algorithm cycle detection, and cron scheduling. | `app/services/workflow.py`, `frontend/src/pages/UserWorkflowEditor.jsx` |
| **Cross-Tenant Data Leakage** | Vector similarity queries and search endpoints risk leaking sensitive customer records across tenants. | **Strict Multi-Tenant Isolation**: Mandatory `workspace_id` scoping on every PostgreSQL query, vector search metadata filter, and memory key. | `app/core/auth.py`, `app/core/rbac.py`, 118 RBAC & isolation tests |
| **Lack of Non-Repudiation & Auditability** | Administrative actions, security policy changes, and agent decisions leave no tamper-proof trace. | **Cryptographic SHA-256 Audit Ledger**: Append-only hash chain linking every audit entry ($H_n = \text{SHA256}(H_{n-1} \,\|\, \text{payload})$) with verification APIs. | `app/services/platform_admin.py`, `test_platform_admin_security.py` |
| **Slow Client Bundles & Accessibility Gaps** | Heavy frontend SPAs suffer from multi-megabyte bundle sizes and fail keyboard navigation standards. | **Dynamic Code Splitting & WCAG-Oriented UX**: Entry JS reduced to 100.20 kB (23.14 kB gzip), drawer focus trapping, skip links, and ARIA live regions. | `vite.config.js`, 42 accessibility & performance vitest tests |
